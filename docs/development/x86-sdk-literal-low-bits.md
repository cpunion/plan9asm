# SDK literal masked minimum predicates

`BindNumericalReadsWithLiteralAlignment` composes the genuine SDK numerical
source/native/object join with the same readonly owner's independently observed
original linked minimum. The ordinary binder still grants no linked-address
bits. The producer has no binder or numerical-address API of its own.

The complete bounded source proof admits full-word literal materialization and
copies, register OR of two sealed carriers, and immediate TEST at every typed
byte/word/dword/qword width only when the mask is wholly covered by the
guaranteed minimum. Offsets retain only their provable low residue. An OR-combined
carrier is not an affine memory origin. Claimed higher floors, missing/foreign
owners, generation changes, closed sources and reentrant Close are rejected.
The existing original source/native instruction, complete function, initializer,
namespace/index/member, profile and lifetime checks remain mandatory.

The result transfer defines only original FLAGS and opaque carrier effects; it
does not initialize numerical GP bytes. The separate canonical bool-byte role
proves the exact low result byte independently.

An orthogonal path-sensitive FLAGS taint tracks uncovered address dependencies.
OR's CF/OF are independently zero; Z/S/P cannot flow into SETcc, Jcc, CMOV or
status readers until a complete covered TEST or independent typed writer clears
their dependency. AF remains undefined under the existing initialization guard.
Mixed CFG paths retain taint; original instruction/path/byte budgets do not grow.

Neither general CMP/AND, uncovered high bits, pointer/vector/frame escapes, cyclic carriers nor mixed-OR
memory reads gain authority. LLVM keeps its existing Go-size alignment rule and
original instruction lowering; no forced align16, guessed linked address or
constant replacement keys/initializers is introduced.

The complete original AMD64 maps source keeps both TEXT functions. Its masked
literal check can bind to the authentic minimum, while whole-file translation
retains Context at the separate incoming caller-pointer address observation
`TESTW $0xff0,AX`. That pointer/page test, caller memory/loop contracts and native
Go entry are not literal-minimum authority. AMD64's three OS profiles are a
source/object binding matrix, not execution or a complete maps compilation pass;
386's ABI0 bool transport remains independent.
